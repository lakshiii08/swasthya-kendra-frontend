⚙️ Installation & Setup
🖥️ Prerequisites

Before running the project install:

Node.js 18+
Git
MetaMask Extension
Supabase Project Setup
🔧 Frontend Setup
1️⃣ Clone Repository
git clone https://github.com/lakshiii08/swasthya-kendra-frontend.git
2️⃣ Navigate to Frontend
cd swasthya-kendra-frontend
3️⃣ Install Dependencies
npm install
4️⃣ Configure Environment Variables

Create .env.local

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url

NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

NEXT_PUBLIC_API_URL=http://localhost:5000
5️⃣ Run Frontend
npm run dev

Frontend runs at:

http://localhost:3000
🔧 Backend Setup
1️⃣ Clone Repository
git clone https://github.com/lakshiii08/swasthya-kendra-backend.git
2️⃣ Navigate to Backend
cd swasthya-kendra-backend
3️⃣ Install Dependencies
npm install
4️⃣ Configure Environment Variables

Create .env

SUPABASE_URL=your_supabase_url

SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

JWT_SECRET=your_jwt_secret

PORT=5000
5️⃣ Run Backend
npm run dev

Backend runs at:

http://localhost:5000
